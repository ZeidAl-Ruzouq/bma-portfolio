# Scoring the BMA

Standalone version of the Creative Atlas Mantis portfolio vertical. Open index.html or visit the GitHub Pages website.

12 fictional student pairs, event scores, real collection artwork images, and synthetic research digests. Student work is sample data. Image and catalog source credits remain in each artwork preview; no image reuse license is implied.

The branches show assignment relationships, not algorithmic similarity. Live Mantis selection highlighting is available in the Mantis extension only.
